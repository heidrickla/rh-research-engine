# Active Search Program

The current principal target is the weighted screening remainder

\[
\mathscr R_q(X)=\text{actual weighted prime-pair covariance}-\text{Hardy--Littlewood model}.
\]

The active-search loop is:

1. measure \(\mathscr R_q(X)\) over geometric scales;
2. fit only simple interpretable lower-order counterterms;
3. inspect local-window energy and Fourier power location;
4. generate candidate analytic identities for the fitted terms;
5. reject candidates violating stored no-go rules;
6. test candidate bounds on synthetic unstable modes;
7. only after a rigorous proof, translate the remainder exponent into an implied bound on \(\Theta\).

A numerical decrease in fitted exponent is not mathematical progress until the corresponding estimate is proved.
