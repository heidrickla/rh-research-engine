# Build 0.11 Notes

Version 0.11 adds the RH property extraction subsystem.

## Added

- Deterministic mathematical object inventory from formula index and durable knowledge.
- Typed property records with epistemic status, assumptions, and provenance hashes.
- Rigorous-only and exploratory implication closure.
- Symmetry and invariant mining hooks.
- Singularity propagation from domain conditions.
- Property graph storage, query API, and module CLI.
- Critical-line versus off-line discriminator analysis that remains fail-closed.
- Synthetic tests proving exploratory and synthetic evidence cannot promote RH-equivalent claims to proof.

## Boundary

Numerical or synthetic evidence remains non-deductive. Discriminator candidates are recorded as candidates only; they cannot mark RH, an RH-equivalent statement, or a Theta endpoint as proved.
